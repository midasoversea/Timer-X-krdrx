# Timer X

Aplikasi Android multi-countdown timer dengan aksen hijau toska.

## Fitur
- Jalankan beberapa timer hitung mundur secara bersamaan.
- Tambah timer melalui tombol FAB (+) di pojok kanan bawah.
- Setiap timer memiliki nama, durasi, kontrol mulai/jeda, lanjutkan, reset, dan hapus.
- Timer berjalan independen dan tetap akurat setelah layar mati atau aplikasi berpindah ke latar belakang.
- Notifikasi saat timer selesai.
- Toggle satu sentuhan untuk berpindah tema terang dan gelap.
- Aksen hijau toska konsisten pada kedua tema.

## Build
Buka proyek dengan Android Studio, lalu jalankan task `:app:assembleDebug`.
